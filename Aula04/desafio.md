# Desafio

Crie uma página (landpage) contendo:

- Nome do evento
- Texto aleatório simulando informações do evento
- Inscrição

## A inscrição deve conter

- Nome, e-mail e telefone, endereço com CEP
- Escolher um minicurso (HTML, CSS ou JavaScript)
- Sugestão de coffee break (café, chá, suco, ...)

- Faça regex para o CEP e telefone, para validar os dados
